# Library Management System – Test Plan

## Objective
To validate that the Library Management System works correctly across:
- Book Management
- Member Management
- Issue & Return flow
- Navigation and menu handling
- Edge cases and invalid inputs

## Scope
- Manual testing only
- Console-based execution
- Admin-driven operations

## Out of Scope
- Performance testing
- Security testing
- Automated unit tests

## Test Approach
- Execute test cases manually via console
- Validate output messages and state transitions
- Verify data consistency across managers

## Entry Criteria
- Application builds successfully
- No compilation errors

## Exit Criteria
- All critical and high-priority test cases pass
- No data corruption observed
