# Navigation & Menu – Test Cases

## TC-NAV-01: Main Menu Navigation
Steps:
1. Launch application

Expected Result:
- Main menu displayed with all options

---

## TC-NAV-02: Back Navigation
Steps:
1. Enter any sub-menu
2. Select Back

Expected Result:
- Returns to main menu

---

## TC-NAV-03: Invalid Menu Option
Steps:
1. Enter non-numeric or out-of-range value

Expected Result:
- Error message shown
- User prompted again

---

## TC-NAV-04: Exit Application
Steps:
1. Select Exit

Expected Result:
- Application terminates gracefully
